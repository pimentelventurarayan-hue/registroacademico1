
 Sistema de Registro Académico

 Descripción
Este proyecto consiste en una aplicación de escritorio
desarrollada en Java Swing para registrar los datos
personales de estudiantes y calcular sus calificaciones.

 Objetivo
Calcular automáticamente la nota final del estudiante
y determinar si aprobó o reprobó la materia.

Funcionalidades
- Registro del nombre completo.
- Registro de matrícula.
- Registro de carrera.
- Ingreso de prácticas.
- Ingreso de parciales.
- Ingreso de asignaciones.
- Ingreso del examen final.
- Cálculo automático de la nota final.
- Validación de calificaciones.
- Resultado de aprobado o reprobado.

 Sistema de calificación

| Evaluación | Puntos |
| Prácticas | 40 |
| Parciales | 20 |
| Asignaciones | 20 |
| Examen Final | 20 |
| Total | 100 |

La nota mínima para aprobar es 60 puntos.

 Tecnologías utilizadas
- Java JDK
- Java Swing
- Apache NetBeans
- Programación Orientada a Objetos (POO)

 Estructura del proyecto

src/

 Ejecución
1. Abrir el proyecto en Apache NetBeans.
2. Abrir la clase Main.java.
3. Ejecutar el programa.
